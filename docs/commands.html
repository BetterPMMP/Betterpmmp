Commands

BetterPMMP adds the vanilla Bedrock commands that PocketMine-MP is missing, with target selectors that also work in plugin commands.

Target selectors

@a          all players
@p          nearest player
@r          random player
@s          the one running the command
@e          all entities
@n          nearest entity

@e[type=zombie,r=10]          zombies within 10 blocks
@a[m=survival,tag=red]        survival players with the tag "red"
@p[x=0,y=64,z=0,rm=5,r=20]    nearest player 5 to 20 blocks from 0 64 0

Filters: x y z r rm dx dy dz c type name tag m l lm, negation with !. When a command gets @a, it runs once per player, so plugin commands like /money @a 100 work too.

Vanilla commands

CommandWhat it does
/executeas, at, positioned, anchored, facing, rotated, in, align, if/unless entity, block, score, run
/scoreboardobjectives, players, sidebar, list and below-name displays
/gameruleall 38 Bedrock game rules, per world
/setblock /fill /cloneedit the world: replace, hollow, outline, keep, destroy; clone with masked and move
/summonevery vanilla and custom creature
/tellraw /titleJSON text with scores and selectors
/function /schedule.mcfunction files, delayed functions
/structuresave and load .mcstructure files, rotate and mirror
/camera /fog /hudcamera presets and fades, fog, hide HUD elements
/tag /damage /rideentity tags, damage with cause, mount mobs
/locate /spreadplayersfind structures, spread players
/playsound /stopsoundvanilla sounds
/tickingarea /daylockkeep areas loaded, stop the day cycle

Examples

/execute as @a at @s if block ~ ~-1 ~ gold_block run effect @s speed 2 1
/scoreboard objectives add kills dummy "Kills"
/scoreboard objectives setdisplay sidebar kills
/tellraw @a {"rawtext":[{"text":"Top: "},{"score":{"name":"@p","objective":"kills"}}]}

Game rules

/gamerule knows all 38 Bedrock rules, for example keepInventory, doDaylightCycle, doMobSpawning, mobGriefing, randomTickSpeed, playersSleepingPercentage, pvp, showCoordinates.

Befehle

BetterPMMP bringt die Vanilla-Befehle von Bedrock mit, die PocketMine-MP fehlen, dazu eine Zielauswahl, die auch in Plugin-Befehlen funktioniert.

Zielauswahl

@a          alle Spieler
@p          nächster Spieler
@r          zufälliger Spieler
@s          wer den Befehl ausführt
@e          alle Wesen
@n          nächstes Wesen

@e[type=zombie,r=10]          Zombies im Umkreis von 10 Blöcken
@a[m=survival,tag=rot]        Survival-Spieler mit dem Tag "rot"
@p[x=0,y=64,z=0,rm=5,r=20]    nächster Spieler 5 bis 20 Blöcke von 0 64 0

Filter: x y z r rm dx dy dz c type name tag m l lm, Verneinung mit !. Bekommt ein Befehl @a, läuft er einmal pro Spieler, deshalb funktionieren auch Plugin-Befehle wie /money @a 100.

Spielregeln

/gamerule kennt alle 38 Bedrock-Regeln, zum Beispiel keepInventory, doDaylightCycle, doMobSpawning, mobGriefing, randomTickSpeed, playersSleepingPercentage, pvp, showCoordinates.
