Installation

BetterPMMP runs wherever PocketMine-MP runs: 64-bit Windows, Linux and macOS. You need the PocketMine PHP binary and the BetterPMMP phar, nothing else.

1. Get the PHP binary

BetterPMMP uses the same PHP build as PocketMine-MP, with the pmmp extensions compiled in. Download the archive for your system from pmmp/PHP-Binaries and unpack it into an empty folder. You should get a folder called bin.

2. Download BetterPMMP

Download BetterPMMP-5.85.phar from the latest release and put it next to the bin folder:

my-server/
├── bin/
└── BetterPMMP-5.85.phar

3. Start the server

Linux and macOS:

./bin/php7/bin/php BetterPMMP-5.85.phar

Windows (Command Prompt in the server folder):

bin\php\php.exe BetterPMMP-5.85.phar

On the first start a setup wizard asks for the language, the server name and the port. Then the server creates server.properties, pocketmine.yml, betterpmmp.yml and the folders worlds and plugins.

4. Join

  • Bedrock Edition: your IP or domain, port 19132 (UDP).
  • Java Edition: your IP or domain, port 25565 (TCP). See Java players.

On a home connection, forward these ports in your router. On a VPS, open them in the firewall.

Moving from PocketMine-MP

  1. Stop the server and back up the worlds folder.
  2. Replace the PocketMine phar with BetterPMMP-5.85.phar.
  3. Start the server. Plugins and worlds stay where they are.

For the new terrain, biomes and structures, create a new world. Java (Anvil) worlds are converted the first time they are loaded.

Running from source

git clone https://github.com/BetterPMMP/Betterpmmp.git
cd Betterpmmp
php src/PocketMine.php

Use the PocketMine PHP binary for php. The vendor folder is part of the repository, you do not need Composer.

Installation

BetterPMMP läuft überall, wo PocketMine-MP läuft: 64-Bit-Windows, Linux und macOS. Du brauchst nur die PocketMine-PHP-Binary und die BetterPMMP-Phar.

1. PHP-Binary holen

BetterPMMP nutzt dasselbe PHP wie PocketMine-MP, mit den pmmp-Erweiterungen. Lade das Archiv für dein System von pmmp/PHP-Binaries herunter und entpacke es in einen leeren Ordner. Danach gibt es dort einen Ordner bin.

2. BetterPMMP herunterladen

Lade BetterPMMP-5.85.phar aus dem neuesten Release herunter und lege sie neben den Ordner bin:

mein-server/
├── bin/
└── BetterPMMP-5.85.phar

3. Server starten

Linux und macOS:

./bin/php7/bin/php BetterPMMP-5.85.phar

Windows (Eingabeaufforderung im Serverordner):

bin\php\php.exe BetterPMMP-5.85.phar

Beim ersten Start fragt ein Einrichtungsassistent nach Sprache, Servername und Port. Danach legt der Server server.properties, pocketmine.yml, betterpmmp.yml und die Ordner worlds und plugins an.

4. Beitreten

  • Bedrock Edition: deine IP oder Domain, Port 19132 (UDP).
  • Java Edition: deine IP oder Domain, Port 25565 (TCP). Siehe Java-Spieler.

Zu Hause gibst du die Ports im Router frei, auf einem VPS in der Firewall.

Umstieg von PocketMine-MP

  1. Server stoppen und den Ordner worlds sichern.
  2. Die PocketMine-Phar durch BetterPMMP-5.85.phar ersetzen.
  3. Server starten. Plugins und Welten bleiben, wo sie sind.

Für das neue Terrain, die Biome und Strukturen eine neue Welt anlegen. Java-Welten (Anvil) werden beim ersten Laden umgewandelt.

Aus dem Quellcode starten

git clone https://github.com/BetterPMMP/Betterpmmp.git
cd Betterpmmp
php src/PocketMine.php

Als php die PocketMine-PHP-Binary verwenden. Der Ordner vendor ist im Repository enthalten, Composer brauchst du nicht.
