Configuration

Everything BetterPMMP adds is set in betterpmmp.yml in the server folder. The file is created on the first start and explains every option in its comments. Changes apply after a restart.

The most important options

graphics:
  vibrant-visuals: true        # allow Vibrant Visuals for Bedrock players

camera:
  presets: true                # camera presets for /camera set

mob-spawning:
  worlds: ["default"]          # "*" = all worlds, "default" = main world
  disabled-worlds: []          # never spawn here, e.g. ["lobby"]
  monsters: true
  animals: true
  max-monsters-per-player: 70

mob-ai:
  pathfinding-ms-per-tick: 6   # main-thread budget for pathfinding
  async-pathfinding: true      # pathfinding in worker threads

hand-swap:
  double-sneak: true           # sneak twice to swap hands

Mob spawning

By default mobs spawn naturally only in the main world, so lobbies and minigame worlds stay empty. Nether and End worlds always behave like vanilla. Every mob category can be switched off on its own.

Game rules

Game rules are not in the config file. Set them in game with /gamerule, per world, like on the official server. They are saved in the world's level.dat under the vanilla names, so a world keeps its rules when you move it.

/gamerule keepInventory true
/gamerule randomTickSpeed 3
/gamerule playersSleepingPercentage 50

Java bridge

The java-bridge section is explained on the Java players page.

Konfiguration

Alles, was BetterPMMP hinzufügt, stellst du in betterpmmp.yml im Serverordner ein. Die Datei wird beim ersten Start angelegt und erklärt jede Einstellung in Kommentaren. Änderungen gelten nach einem Neustart.

Die wichtigsten Einstellungen

graphics:
  vibrant-visuals: true        # Vibrant Visuals für Bedrock-Spieler erlauben

camera:
  presets: true                # Kamera-Voreinstellungen für /camera set

mob-spawning:
  worlds: ["default"]          # "*" = alle Welten, "default" = Hauptwelt
  disabled-worlds: []          # hier nie, z. B. ["lobby"]
  monsters: true
  animals: true
  max-monsters-per-player: 70

mob-ai:
  pathfinding-ms-per-tick: 6   # Zeitbudget im Hauptthread für Wegfindung
  async-pathfinding: true      # Wegfindung in eigenen Threads

hand-swap:
  double-sneak: true           # zweimal schleichen tauscht die Hände

Mob-Spawning

Standardmäßig spawnen Mobs nur in der Hauptwelt natürlich, Lobbys und Minispiel-Welten bleiben leer. Nether- und End-Welten verhalten sich immer wie Vanilla. Jede Mob-Gruppe lässt sich einzeln abschalten.

Spielregeln

Spielregeln stehen nicht in der Config. Du setzt sie im Spiel mit /gamerule, pro Welt, wie auf dem offiziellen Server. Sie werden unter den Vanilla-Namen in der level.dat der Welt gespeichert und bleiben erhalten, wenn du die Welt verschiebst.

/gamerule keepInventory true
/gamerule randomTickSpeed 3
/gamerule playersSleepingPercentage 50
