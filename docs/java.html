Java players

BetterPMMP has a built-in bridge for Minecraft: Java Edition, based on ViaProxy and ViaBedrock. Java and Bedrock players play on the same world at the same time.

How it works

  1. On the first start BetterPMMP downloads Java 21 (if none is installed) and ViaProxy into the folder java-bridge.
  2. ViaProxy starts together with the server, restarts after a crash and stops with the server.
  3. Java players connect to your address on port 25565. The bridge translates between Java and Bedrock.

Ports

  • 25565 TCP: the game.
  • 25566 TCP: resource packs for Java players (textures of custom content and the server's packs).

Settings

java-bridge:
  enabled: true              # false = no Java players
  port: 25565                # Java port (TCP)
  auto-download: true        # download Java and ViaProxy automatically
  online-mode: true          # only bought Java accounts
  name-prefix: "J_"          # Java players appear as J_Steve
  memory: "512M"             # memory for ViaProxy
  resource-pack-port: 25566  # resource packs for Java, 0 = off
  public-address: ""         # empty = detect the public IP
  chat-forms: false          # true = forms as a chat menu
  real-light: true           # send real light (good for shaders)

What Java players can do

Building, fighting, crafting, furnaces, brewing stands, hoppers, chests, dispensers and droppers, minecarts and boats with chests, the smithing table, fireworks and dyed armour. Names above mobs and holograms are shown, forms open as windows or as a chat menu.

Not yet available for Java players: anvil, enchanting table, grindstone, stonecutter, loom, cartography table, crafter, beacon and villager trading.

Java-Spieler

BetterPMMP hat eine eingebaute Bridge für Minecraft: Java Edition, auf Basis von ViaProxy und ViaBedrock. Java- und Bedrock-Spieler spielen gleichzeitig in derselben Welt.

So funktioniert es

  1. Beim ersten Start lädt BetterPMMP Java 21 (falls keins installiert ist) und ViaProxy in den Ordner java-bridge.
  2. ViaProxy startet mit dem Server, startet nach einem Absturz neu und stoppt mit dem Server.
  3. Java-Spieler verbinden sich mit deiner Adresse auf Port 25565. Die Bridge übersetzt zwischen Java und Bedrock.

Ports

  • 25565 TCP: das Spiel.
  • 25566 TCP: Resource-Packs für Java-Spieler (Texturen eigener Inhalte und die Packs des Servers).

Einstellungen

java-bridge:
  enabled: true              # false = keine Java-Spieler
  port: 25565                # Java-Port (TCP)
  auto-download: true        # Java und ViaProxy automatisch laden
  online-mode: true          # nur gekaufte Java-Konten
  name-prefix: "J_"          # Java-Spieler heißen z. B. J_Steve
  memory: "512M"             # Arbeitsspeicher für ViaProxy
  resource-pack-port: 25566  # Resource-Packs für Java, 0 = aus
  public-address: ""         # leer = öffentliche IP automatisch
  chat-forms: false          # true = Formulare als Chat-Menü
  real-light: true           # echtes Licht schicken (gut für Shader)

Was Java-Spieler können

Bauen, Kämpfen, Craften, Öfen, Braustände, Trichter, Truhen, Spender und Werfer, Loren und Boote mit Truhe, der Schmiedetisch, Feuerwerk und gefärbte Rüstung. Namen über Mobs und Hologramme werden angezeigt, Formulare öffnen sich als Fenster oder als Chat-Menü.

Für Java-Spieler noch nicht verfügbar: Amboss, Zaubertisch, Schleifstein, Steinsäge, Webstuhl, Kartentisch, Crafter, Leuchtfeuer und Handel mit Dorfbewohnern.
