AboutÜber das Plugin

The official development tool of PocketMine-MP. With DevTools the server loads plugins from folders, so you can edit a plugin and restart without packing it first. /makeplugin builds a .phar from a folder plugin. Works on BetterPMMP because BetterPMMP keeps the PocketMine-MP 5 plugin API.Das offizielle Entwickler-Werkzeug von PocketMine-MP. Mit DevTools lädt der Server Plugins aus Ordnern, du kannst also ein Plugin ändern und neu starten, ohne es vorher zu packen. /makeplugin baut aus einem Ordner-Plugin eine .phar. Läuft auf BetterPMMP, weil BetterPMMP die Plugin-API von PocketMine-MP 5 behält.
