Submit a plugin

Made a plugin for BetterPMMP or PocketMine-MP 5? Share it here. Every submission is checked by hand before it appears in the list.

Requirements

  • The plugin runs on BetterPMMP (API 5).
  • The source code is public, for example on GitHub.
  • There is a .phar to download, for example as a GitHub release or on Poggit.
  • No malware, no hidden tracking, no copied plugins under a new name.

How to submit

  1. Open the submission form on GitHub (you need a free GitHub account).
  2. Fill in name, description, link to the source and the download.
  3. After the check the plugin gets its own page in the list.

Plugin einreichen

Du hast ein Plugin für BetterPMMP oder PocketMine-MP 5 gebaut? Teile es hier. Jede Einreichung wird von Hand geprüft, bevor sie in der Liste erscheint.

Voraussetzungen

  • Das Plugin läuft auf BetterPMMP (API 5).
  • Der Quellcode ist öffentlich, zum Beispiel auf GitHub.
  • Es gibt eine .phar zum Herunterladen, zum Beispiel als GitHub-Release oder auf Poggit.
  • Keine Schadsoftware, kein heimliches Tracking, keine kopierten Plugins unter neuem Namen.

So reichst du ein

  1. Das Formular auf GitHub öffnen (du brauchst ein kostenloses GitHub-Konto).
  2. Name, Beschreibung, Link zum Quellcode und zum Download eintragen.
  3. Nach der Prüfung bekommt das Plugin eine eigene Seite in der Liste.
